Privacy policy

Last updated 13 October 2026.

On Pace is a personal app with one user: its developer, Maarten Gerritse. Nobody else can sign in.

What data it reads

With the user's permission, On Pace reads activity and fitness, health metrics, sleep, profile and settings data from the Google Health API, using read-only access. It never writes to or deletes data in the user's Google account.

How the data is used and stored

The data is used only to show the user's own charts, progress against targets and weekly summaries. It is stored in a private database controlled by the user. Weekly summary numbers (not raw data) may be sent to the Anthropic API to write a short text summary.

The data is not sold, shared with third parties for advertising, or used for any other purpose. On Pace's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

The user can revoke access at any time at myaccount.google.com/permissions and delete the app's database.
